# 아이템 4종 사용 안내

`MainPlay`에 폭탄·빙결·보호막·유도 미사일의 데이터, 프리팹, 아이콘, 효과음, 점수·콤보·경과 시간 HUD를 연결했다. 별도의 Inspector 연결 없이 씬을 열고 Play할 수 있다.

## 한 판에서의 동작

- 3초 준비가 끝난 뒤 플레이 시간 4~6초에 첫 아이템을 시도한다. 이후 3~5초마다 공급한다.
- 네 종류는 가중치 1:1:1:1로 독립 추첨한다. 이 비율은 초기 프로젝트 선택이며 원작 내부 확률이 아니다.
- 미획득 최대 3개, 유지 18초, 마지막 2초 깜빡임을 적용한다. 활성 효과와 장착한 보호막은 최대 개수에 포함하지 않는다.
- 맵의 획득물은 표시 폭 1.4, 획득 반경 0.7로 최초 크기의 2배다. 플레이어 표시 크기는 유지하고 효과 범위는 각 아이템 설정을 따른다. 생성 시 적과의 최소 간격은 설정값과 반경 합 중 큰 값을 사용해 커진 획득물이 적과 겹치지 않게 한다.
- 위치 후보 32개를 검사하고 실패하면 1초 뒤 한 건만 재시도한다. 배치 조건을 무시하거나 실패분을 몰아서 생성하지 않는다.
- 폭탄은 반경 2.4, 0.35초 동안 범위에 들어온 활성 적을 처치한다.
- 빙결은 반경 3.5 안의 적을 발동 순간 한 번, 3.9초 동안 얼린다. 본체 또는 장착한 보호막으로 접촉하면 쇄빙한다.
- 보호막은 플레이어를 따라가는 Bubble Shield다. 일반 적이 버블에 닿으면 소모되어 접촉 위치에 폭발을 남긴다. 초기 버블 반경은 0.65, 폭발 반경은 2, 폭발은 0.35초다.
- 보호막은 시간 경과만으로 사라지지 않는다. 장착 중 적 접촉 반경은 본체 0.25 대신 보호막 반경 0.65를 사용한다. 얼어 있는 적도 이 반경에서 쇄빙하며 보호막을 터뜨리지 않는다. 아이템 획득과 경계 반경은 본체 기준을 유지한다. 재획득해도 장착 버블은 1개만 유지하며 이미 터진 폭발은 취소하지 않는다.
- 유도 미사일은 획득 위치에서 4발이 퍼져 나와 활성 적을 추적하고, 접촉하면 주변을 폭발시킨다. 표적이 사라지면 다시 찾으며, 재획득해도 기존 탄은 유지한다. 비행 수명은 4초이며 만료 시 현재 위치에서 폭발한다. 자세한 설정은 `Docs/HOMING_MISSILES.md`에 정리한다.
- 폭탄 → 빙결 → 유도 미사일 → 보호막 접촉 폭발 → 남은 적과 본체 접촉 → 처치 묶음 점수 순서로 처리한다. 폭발 범위 밖 접촉까지 무효화하는 전역 무적은 없다.
- 기본 점수 100에 콤보 배율을 적용하고 64비트로 누적한다. R 키 재시작 시 적·아이템·효과·점수·예약을 초기화한다.

## 생성과 재사용

획득물은 공통 템플릿을 복제해 풀에서 재사용한다. 획득 후 효과는 각 종류의 프리팹으로 만들고 프리팹별 풀에서 재사용한다. 효과의 판정·수명과 표현은 분리되어 있다. 기존 `BombItem` 호환 클래스도 남겼지만 현재 MainPlay의 `Items`에는 일반 `ItemSystem`이 연결되어 있다.

`RedDot Dodge > Configure Three Items`는 초기 콘텐츠와 연결을 복구하는 개발 메뉴다. 실행하면 세 종류의 초기 가중치와 효과 수치를 다시 설정하므로 밸런스 조정 후에는 의도한 경우에만 사용한다. 보호막 획득 아이콘은 사용자가 제공한 `Assets/Main/04_Resource/Items/pickup_shield.png`를 사용한다.

`RedDot Dodge > Add Homing Missiles`는 기존 설정을 유지하면서 미사일 데이터·표현과 MainPlay 연결을 추가한다. 이미 추가된 미사일의 가중치와 효과 수치는 다시 초기화하지 않는다. 기존 3종 설정 도구도 네 번째 항목을 제거하지 않도록 수정했다.

보호막과 미사일의 사용자 제공 아이콘은 각각 `Assets/Main/04_Resource/Items/pickup_shield.png`, `pickup_interceptor_missile.png`다. `RedDot Dodge > Update Pickup Icons`는 두 이미지의 Sprite 임포트와 MainPlay 참조만 갱신하며 크기와 효과 설정은 바꾸지 않는다. 콘텐츠 생성 도구에서도 같은 경로를 사용한다.

## 검증

2026-11-19 밸런스 조정은 폭탄 반경 2.4, 빙결 3.9초, 미사일 4발·비행 4초, 보호막 장착 중 적 접촉 반경 0.65를 적용했다. 이번 변경은 런타임·에디터 C# 컴파일만 확인했으며 Play Mode 검사는 실행하지 않았다. 아래 실행 기록은 조정 전 설정 기준이다.

- 아래 32개·12개는 기존 3종 구현 당시의 검사 기록이다. 미사일은 별도 `ArtExports/MissileQA/result.json`에 실제 MainPlay에서 발사·표시·처치·점수·재시작을 확인한 결과가 있다. 사용자의 추가 테스트 중단 요청 이후에는 검사를 반복하지 않았다.

- 격리 프로젝트에서 기존 공급·폭탄·빙결·콤보·풀·방어 확장 검사 32개를 통과했다.
- 실제 MainPlay Play Mode에서 실제 에셋과 프리팹을 사용한 자동 검사 12개를 통과했다. 검사는 위치와 적을 구성한 뒤 전투 틱을 수동 호출한다.
- 실제 씬 검사에는 보호막 60초 이후 유지, 확대된 버블 접촉, 빙결 접촉, 재획득, 중첩 폭발, 전역 무적 미부여, 종료와 재시작을 포함한다.
- `RedDot Dodge > Validate Three Items`에서 재실행할 수 있다. 실행 전 씬을 저장하며, 검사 후 Play를 종료한다.
- 결과와 실제 렌더 미리보기는 `ArtExports/ItemQA/validation.json`, `Items_Overview.png`, `Bomb_Active.png`, `Freeze_Active.png`, `Shield_Burst.png`에 저장한다.
- 위 미리보기는 최종 보호막 전용 초록색 셰이더 적용 직전의 캡처다. 사용자가 직접 플레이테스트하기로 하여 최종 색상 저장 후 검사를 반복하지 않았다.

최고 점수 저장·메뉴·일시정지·나머지 적 패턴의 본편 통합은 별도다. BEST는 기존 HUD 표시이며 저장 구현을 검증한 것은 아니다. Android 실기기, 장시간 밸런스, 오디오 청취와 성능 측정은 아직 확인하지 않았다.

## 보호막 참고와 프로젝트 선택

[MobyGames 원작 설명](https://www.mobygames.com/game/50920/tilt-to-live/)과 [당시 공략](https://iphoneac.com/tilttolive.html)은 Bubble Shield가 한 번의 접촉에서 터져 주변 적을 제거하며, 버블의 접촉 범위가 본체보다 커지는 동작을 설명한다. 원작의 정확한 반경·폭발 시간·재획득 정책을 확인한 것은 아니다. 위 수치, 시간 만료 없음과 장착 1개 정책은 본 프로젝트에서 명시한 초기 규칙이다.

새 종류 추가의 역할과 수명주기는 [아이템 효과 구조](ITEM_EFFECT_ARCHITECTURE.md)를 참고한다.
