# InGame 한 씬 전환

`InGame`을 실행하면 메인 메뉴에서 대기합니다. `GameStart_Btn`의 OnClick은 씬의 `InGame Flow` 오브젝트에 있는 `InGameFlowController.OnGameStartActioned`에 연결했습니다.

1. 시작 버튼 입력을 잠그고 제목은 위로, 시작·안내·설정 버튼은 아래로 날려 보냅니다. 메뉴 내용은 함께 사라집니다.
2. 메뉴 퇴장 후 게임 월드와 인게임 Canvas를 켜고, HUD는 위에서 내려오며 경기장 영역은 아래에서 올라옵니다.
3. 전환 완료 시 `BeginRound()`를 호출합니다. 기존 준비 시간에 연동된 3 → 2 → 1 이후 플레이어 조작과 게임 진행이 시작됩니다.

현재 전환은 메뉴 퇴장 0.36초와 버튼 간 지연 최대 0.07초, 인게임 등장 0.26초를 합해 약 0.69초입니다. `InGame Flow`의 Inspector에서 메뉴 퇴장·인게임 등장·복귀 시간을 조정할 수 있습니다. UI 애니메이션은 DOTween Sequence로 묶고 게임 시간 배율에 독립적으로 진행합니다.

`EdgeChaseWaveHost`는 최초 초기화와 한 판의 시작·정리를 분리했습니다. `BeginRound()`는 초기화를 보장하고 새 판을 시작하며, `StopRound()`는 적·아이템·효과·점수·예약을 정리하고 플레이어를 숨깁니다. 메뉴와 전환 중에는 R 키로 시작할 수 없고, 게임 진입 후에는 기존 R 키 재시작을 사용합니다.

`MainPlay`는 자동 시작 기본값을 유지하고, `InGame`의 호스트만 `Start Automatically`를 껐습니다. 초기 Canvas 표시와 시작 버튼, CanvasGroup, 전환 대상은 InGame 씬 파일에 연결되어 있습니다. `ReturnToMenu()`는 향후 결과 화면의 메뉴 버튼에서 사용할 수 있으며, 위치와 투명도를 복원하고 메뉴 대기로 돌아갑니다. 안내·설정·일시정지·결과 화면 기능은 이번 전환 구현에 추가하지 않았습니다.

이번 작업은 Computer Use 없이 코드와 씬 파일을 직접 수정했습니다. 컴파일 검사와 Play Mode 테스트는 실행하지 않았습니다. Unity에 이전 씬 상태가 열려 있다면 저장된 InGame 씬을 다시 불러와 사용합니다.
